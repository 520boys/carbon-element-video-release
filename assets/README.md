# 发布素材

当前已接入以下公开素材：

- `app_icon.png`：应用图标，用于 README、网页图标和版本清单。
- `screenshots/home.png`：首页预览。
- `screenshots/1.png`、`screenshots/2.png`：个人中心、搜索等界面预览。
- `screenshots/3.png` 至 `screenshots/9.png`：更多真实 App 界面。
- `social-cover.png`：社交分享封面素材；建议后续替换为 1280 x 640 的横向图，便于 GitHub/Open Graph 分享展示。

不要放入 keystore、接口密钥、推送凭据、用户数据、未公开运营素材或 APK/AAB 文件。
