# Carbon Element Video Privacy Notice

Last updated: complete this date before public launch.

Carbon Element Video provides content browsing, playback, community, account, membership, and reward features. This notice summarizes information that may be processed and why. The operator must review and complete this notice according to the actual deployment, enabled SDKs, and applicable laws before public distribution.

## Information That May Be Processed

| Category | Purpose |
| --- | --- |
| Account profile, including nickname, avatar, and user identifier | Authentication, profile display, comments, invitations, and membership services. |
| Activity data, including comments, danmaku, favorites, watchlists, and playback progress | Community features, watch history, resume playback, recommendations, and operations. |
| Device and network information | Fault diagnosis, playback optimization, download network policies, and security controls. |
| Push identifier and notification permission state | System announcements, watchlist updates, and membership reminders after authorization. |
| Task, gold-credit, and exchange records | Check-ins, reward delivery, membership exchanges, and order records. |

## Permissions

- **Network**: requests content, account, operations, and playback services.
- **Camera**: used only when the user actively opens the QR scanner.
- **Notifications**: used only after user authorization.
- **Storage-related access**: used for user-initiated offline downloads, cache management, and local playback.

## Third-Party Services

The application may use third-party SDKs for notifications, playback, image loading, or QR scanning. Before public launch, the operator must disclose each enabled SDK, its purpose, data categories, privacy-policy link, and update date here.

## Security and Contact

Account tokens should be stored using secure storage. Production services should use HTTPS, access controls, and appropriate audit measures. Users may use the in-app feedback entry to request information, corrections, or deletion related to their account.

Public support email: complete before public launch.

This notice is not a substitute for legal advice or a final legal privacy policy.
