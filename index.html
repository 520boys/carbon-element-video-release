碳元素视频

看见世界的每一面

碳元素视频是全平台影视内容服务，统一连接内容浏览、播放、追剧、互动与运营能力。当前已发布 Android 客户端，后续终端将复用同一套账号、会员与内容体系。

下载最新 Android 安装包 查看更新日志

真实界面预览

核心体验

  • 分类筛选、影视搜索、排行榜与个性化推荐
  • 多线路播放、选集、清晰度能力展示和观看历史
  • 追剧、收藏、弹幕、评论、回复、点赞和举报
  • 会员权益、任务签到、金豆商城、兑换和邀请奖励
  • 离线下载、缓存管理与网络策略控制

技术架构

  • Flutter 与 Dart：Android 客户端、播放器、弹幕互动、下载缓存和二维码能力。
  • Vue 3、TypeScript、Vite、Element Plus：基于 CoolAdmin Vue 的运营管理端。
  • Node.js、TypeScript、CoolAdmin Midway、Koa、TypeORM：内容与用户服务端。
  • MySQL：影片、线路、账号、会员、金豆、邀请与运营配置数据。
  • 苹果 CMS JSON/XML：多资源站内容采集、分类映射、影片合并与线路管理。

安装与更新

请从 GitHub Releases 下载官方 APK。每个版本均应提供版本说明和 SHA-256 校验值。应用功能和内容可根据服务端运营配置更新。
